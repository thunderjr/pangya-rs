04 / Proof gates

What can stop the build.

Four gates deliberately block forward motion when assumptions are still guesses.

Gate A / binary truth

Protocol parity

PangCrypt vectors, every split boundary, multiple frames per read, invalid keys and truncated bodies. No fixture, no handler.

Gate B / client truth

U.S. 852 acceptance

The preserved client—not an upstream README—decides whether hello, LZO, packet order and field widths are correct.

Gate C / legal truth

Provenance

GPL/AGPL and no-license code remains behavior-only unless the project's license changes. Adapted permissive material keeps notices.

Gate D / durable truth

Exactly once

Handover and reward races are tested at the database boundary. Client retries never mint a second token, item or payout.

05 / Reference map

Use each source for one job.

No single legacy repository gets to dictate the Rust design.

Wire oracle

PangCrypt

Transport algorithm, 4-bit key, 8 KiB oracle data and golden ciphertext/plaintext vectors.

Packet corpus

PacketDoc

260 indexed packet definitions across login, game and message directions; always fixture-check WIP layouts.

Modern flow

alter-pangya

U.S. 852 typed handlers, match events and PostgreSQL repositories. No license found: facts only, no copying.

Actor model

Pangbox Server

ISC-licensed typed messages, room ownership, Minibox topology and compact SQL schema.

Feature breadth

SuperSS

Largest feature and database command inventory. Use to enumerate outcomes, never to import legacy architecture wholesale.

US S8 behavior

Py_Source_US

U.S. 852/824 behavior and feature clues under GPL-3.0—a differential reference, not permissive source material.

Client edge

Rugburn

Network redirection and client support. Keep it external; do not redistribute separately licensed IJL assets here.

Disk formats

PangFiles + PangLib

IFF, PAK, XTEA and updatelist behavior. Start with safe explicit IFF parsing; defer the rest.

First implementation move

Start below the gameplay layer.

The first commit should not create a room, character, or shop. It should make one encrypted frame boring: reproducible, bounded, attributed and impossible to panic.

Open the progress board
  1. Resolve final license and LZO ADR.
  2. Initialize Cargo workspace and CI lints.
  3. Port attributed oracle tables.
  4. Pass PangCrypt client vectors.
  5. Decompress PangCrypt server vectors.
  6. Implement bounded Tokio frame codec.
  7. Test every fragmentation boundary.
  8. Add synthetic hello/login packets.
  9. Only then attach a real U.S. 852 client.
Definition of first proof

A corrupted or oversized packet closes one connection, allocates within limits, emits a redacted error, and leaves every other listener alive.
