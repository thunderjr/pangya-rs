# ADR-0001: Project license

- Status: **Accepted**
- Date: 2026-08-05

## Context

This matches the owner-approved permissive strategy and permits ISC adaptations while keeping GPL/AGPL/unlicensed sources behavior-only.

## Decision

License the project under either MIT or Apache-2.0 at the recipient’s option. Preserve upstream notices in THIRD_PARTY_NOTICES.md.

## Consequences

The decision is normative for the M1 foundation. Reversal requires a superseding ADR and updated evidence.
