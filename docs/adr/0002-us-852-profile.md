# ADR-0002: U.S. 852 compatibility profile

- Status: **Accepted**
- Date: 2026-08-05

## Context

A single explicit profile prevents accidental cross-version layout assumptions.

## Decision

U.S. 852.00 / GB.852 is the only initial compatibility profile. New regions or versions require fixtures and integration coverage.

## Consequences

The decision is normative for the M1 foundation. Reversal requires a superseding ADR and updated evidence.
